# Sicherheitsrichtlinie

## Geltungsbereich

Dieses Repository enthält ausschließlich statische Webdesign-Demos und Frontend-Konzepte. Es verarbeitet keine vertraulichen Kundendaten und stellt keine produktiven Backend-Dienste bereit.

## Sicherheitsmeldungen

Wenn du eine Sicherheitslücke im Quellcode findest, melde sie bitte vertraulich über die im GitHub-Profil angegebenen Kontaktmöglichkeiten und veröffentliche Details nicht vor einer gemeinsamen Klärung.

Bitte beschreibe:

- betroffene Datei oder Komponente
- reproduzierbare Schritte
- erwartetes und tatsächliches Verhalten
- mögliche Auswirkungen

## Verantwortungsvolle Nutzung

Tests dürfen ausschließlich an eigenen Systemen oder mit ausdrücklicher Genehmigung durchgeführt werden.
